GT STANDARD — PRIMARY HEADING FONT (5 weights via @font-face):
  Selected this premium Swiss-designed sans-serif as the headline
  typeface for its clean, modern geometry that conveys professionalism:

  - Light (300): gt-standard-light.woff2
    Used for subtle, refined subheadings and captions.

  - Regular (400): gt-standard-regular.woff2
    Base heading weight — used across most h1-h6 elements.

  - Regular Italic (400): gt-standard-regular-oblique.woff2
    For emphasized or decorative heading text.

  - Medium (500): gt-standard-medium.woff2
    For medium-emphasis headings and navigation.

  - Semibold (600): gt-standard-semibold.woff2
    For high-emphasis headings and hero text.

  Font application rule: h1, h2, h3, h4, h5, h6 { font-family: 'GT Standard',
  sans-serif; } — all headings automatically use GT Standard throughout the
  application.

GOOGLE FONTS — BODY & DECORATIVE FONTS:

  - DM Sans (variable weight 100-1000, normal + italic):
    Selected as the primary body/sans-serif font via
    @import url('https://fonts.googleapis.com/css2?family=DM+Sans...')
    Chosen for its clean readability at small sizes, geometric
    construction that pairs well with GT Standard, and extensive
    weight range for flexible typographic hierarchy.

  - Playfair Display (variable weight 400-900, normal + italic):
    Selected as the decorative serif font via
    @import url('https://fonts.googleapis.com/css2?family=Playfair+Display...')
    Used selectively (font-serif class) for premium, traditional
    accents — the hero section's large serif watermark text ("DELTA"),
    stat values ("27+", "1.5Cr+"), and other moments requiring
    classic elegance.

FONT STACK STRATEGY:
  - Headings → GT Standard (custom premium sans-serif)
  - Body text → DM Sans (clean geometric sans-serif, fallback: sans-serif)
  - Decorative → Playfair Display (elegant serif accents)
  This three-tier system creates clear visual hierarchy while maintaining
  a cohesive premium aesthetic appropriate for a trophy manufacturing brand.

────────────────────────────────────────────────────────────────────────────────
B.1  ANIMATION FRAMEWORK & STANDARDS
────────────────────────────────────────────────────────────────────────────────

Established the animation design language used consistently across the
entire application:

CUSTOM EASING CURVE:
  - Primary easing: [0.16, 1, 0.3, 1]
    A custom cubic-bezier that creates a premium, spring-like
    deceleration — feels natural and high-end. Used across:
    * All page section entrances (Hero, About, Quality, etc.)
    * Chat panel open/close transitions
    * Navigation bar slide animations
    * Image hover transformations
    * All whileInView scroll-triggered reveals

ANIMATION PATTERNS (3 core patterns established):

  Pattern 1 — Scroll-Triggered Reveal (whileInView):
    * initial: { opacity: 0, y: 20 }
    * whileInView: { opacity: 1, y: 0 }
    * viewport: { once: true, margin: "-10%" }
    * Transition: duration 0.6-0.8s with custom easing
    * Staggered delays (0.05s increments) for list items and grids
    * Used on: every home page section, stat cards, feature cards,
      category cards, gallery images, process steps, product cards

  Pattern 2 — Mount/Unmount Transitions (AnimatePresence):
    * mode="wait" for sequential (one out before next in)
    * Used for: image carousels, stat cycling, chat panel open/close,
      AI interpretation panel, navigation overlays
    * Smooth opacity + position transitions

  Pattern 3 — Micro-Interactions (motion elements):
    * whileHover: { scale: 1.05 } — buttons, cards, FAB
    * whileTap: { scale: 0.95 } — interactive elements
    * group-hover effects — image scales, underline expansions,
      color transitions
    * Duration: 300-700ms depending on element size and context

TRANSITION PROPERTIES STANDARDIZED:
  - Image hover scale: transition-transform duration-500 or duration-700
  - Underline animations: transition-all duration-300 or duration-500
  - Color/background transitions: transition-colors
  - Opacity transitions: transition-opacity
  - All with consistent eased timing

================================================================================

────────────────────────────────────────────────────────────────────────────────
E.1  BREAKPOINT STRATEGY
────────────────────────────────────────────────────────────────────────────────

Established the responsive design breakpoints and patterns used across
the entire application:

MOBILE (default, sm: 640px):
  - Single column layouts (grid-cols-1)
  - Stacked sections, smaller text sizes
  - Full-width buttons and CTAs
  - Hamburger menu navigation
  - Optimized touch targets (minimum 44px)

TABLET (md: 768px):
  - 2-column grids where appropriate (sm:grid-cols-2)
  - Larger typography (md:text-5xl, etc.)
  - Responsive aspect ratios (md:aspect-[21/9])
  - Some desktop features begin appearing

DESKTOP (lg: 1024px):
  - Full 12-column grid system active
  - Navigation switches to horizontal links
  - Multi-column layouts (3-4 columns)
  - Larger visual elements (lg:text-7xl, lg:h-[500px])
  - Asymmetrical grids deploy
  - Scale effects activate (lg:scale-90)

EXTRA LARGE (xl: 1280px, 2xl: 1536px):
  - Max-width containers cap at 1536px
  - Content centers with generous padding
  - 4-column grids where beneficial

────────────────────────────────────────────────────────────────────────────────
E.2  RESPONSIVE PATTERNS IMPLEMENTED
────────────────────────────────────────────────────────────────────────────────

Defined and applied consistent responsive patterns:

GRID ADAPTATION:
  - 1 col (mobile) → 2 cols (tablet) → 3 cols (desktop) → 4 cols
    (extra large)
  - Applied to: product listings, category grids, search results,
    gallery images, similar products

TYPOGRAPHY SCALING:
  - Headings scale up at each breakpoint (text-4xl → md:text-5xl →
    lg:text-7xl)
  - Body text: text-base → md:text-lg
  - Small text: text-xs → text-sm
  - Consistent scaling ratios maintain hierarchy

SPACING ADAPTATION:
  - Section padding: py-20 → md:py-32
  - Container padding: px-6 → md:px-12
  - Card padding: p-6 → md:p-10 → lg:p-12
  - Gap spacing: gap-4 → md:gap-6 → lg:gap-8

IMAGE HANDLING:
  - Aspect ratios adapt: aspect-[4/5] mobile → md:aspect-[21/9]
    tablet → lg:aspect-[2.5/1] desktop
  - Object-fit: cover maintains composition
  - Responsive image containers prevent layout shift

NAVIGATION ADAPTATION:
  - Mobile: hamburger menu + full-screen overlay
  - Desktop: horizontal link bar with dropdowns
  - Search and Contact always accessible at both sizes

G.3  ACCESSIBILITY CONSIDERATIONS
────────────────────────────────────────────────────────────────────────────────

Incorporated accessibility in the design system:

  - Color contrast: Dark maroon (#35020D) on cream (#ffffe3) provides
    strong contrast ratio for readability
  - Focus states: Focus rings on interactive elements using
    --ring color
  - ARIA labels: Applied to icon-only buttons (ChatFAB, search

    nav, main, aside, footer
  - Keyboard navigation: Interactive elements are buttons and links

    (not too fast or slow)
  - Screen reader: alt text on images, aria-labels on icon buttons,
    semantic structure
